# 今日训练 · 训练与营养提醒 App

一个可以安装到手机主屏幕的网页应用（PWA），按照你的训练计划告诉你**今天练什么、做哪些动作**，以及**今天该摄入多少营养**。不需要服务器，数据只保存在你自己的手机里。

## 功能

- **今天**：自动算出今天对应计划里的哪一天，显示训练部位和动作（组数 × 次数 × 重量），每做完一组点一下打卡，有进度条
- **未来 7 天预览**：顶部一排可以点开查看之后几天练什么
- **训练计划**：两种模式
  - 按星期：周一到周日固定安排
  - 循环：N 天一轮（例如“推/拉/腿/休”4 天循环），设定第 1 天的日期即可
  - 可随意增删改动作、组数、次数、重量，自动保存
- **营养**：填写性别、年龄、身高、体重、活动量和目标（增肌 / 减脂 / 维持），自动算出
  - 训练日 / 休息日分开的热量、蛋白质、碳水、脂肪目标（训练日碳水更高）
  - 按你的训练时间安排餐次（练前加餐、练后餐），每餐的宏量营养和食物建议
  - 每日饮水目标和喝水打卡
- **提醒**
  - 应用内通知：早晨推送今日训练 + 营养摘要，训练前 15 分钟、每餐时间提醒
  - **导出到手机日历（.ics）**：导出未来 4 周的提醒，导入系统日历后即使不打开 App 也会准时提醒（推荐）
- 数据备份导出 / 导入

## 使用方法

### 在手机上用（推荐）

把这个仓库发布到 GitHub Pages：仓库 **Settings → Pages → Source 选 `Deploy from a branch`**，选择分支和根目录 `/`，保存后得到一个网址。

用手机打开该网址：
- iPhone：Safari → 分享 → **添加到主屏幕**
- Android：Chrome → 菜单 → **安装应用 / 添加到主屏幕**

### 在电脑上本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 营养计算说明

- 基础代谢：Mifflin-St Jeor 公式
- 每日热量 = 基础代谢 × 活动系数 + 训练消耗（训练日约 4 千卡/kg）+ 目标调整（增肌 +250，减脂 −450）
- 蛋白质：增肌 2.0g/kg，减脂 2.2g/kg，维持 1.8g/kg
- 脂肪约 0.8–1.0g/kg，剩余热量全部给碳水
- 结果仅供参考，请按每周体重变化微调
