# 5/3/1 训练助手

一个可以安装到手机主屏幕的网页 App（PWA）。内置「3 个月力量训练挑战计划」（5/3/1，一周四练），根据你的身体数据、最大重量、伤病、器械和动作偏好，生成每天的训练和营养计划。数据只保存在你自己的手机里。

## 第一次打开：问卷

1. **基础信息**：性别、年龄、身高、体重、活动量、目标（增肌 / 减脂 / 维持）→ 用来算营养
2. **身体与器械**：伤病部位（肩 / 腰 / 膝 / 肘 / 手腕），健身房还是家里，有哪些器械
3. **主项与最大重量**：推举、硬拉、卧推、深蹲。填「重量 + 能做几次」，自动估算 1RM，TM = 1RM × 90%
   - 根据伤病和器械自动推荐替代动作，例如腰不好：传统硬拉 → 六角杠铃硬拉，站姿推举 → 坐姿推举
4. **训练安排与偏好**：选 4 个训练日、训练时间、从第几周开始；给动作点 ❤️ 喜欢 / 🚫 不做，也可以手动添加你习惯的动作
5. **生成计划**：显示 12 周的 TM、本周的训练和每日营养目标

之后随时可以在「我的 → 重新填写问卷」修改。

## 每天使用

- **今天想练什么**：默认按固定周期推荐（⭐），也可以按状态自己选推举日 / 硬拉日 / 卧推日 / 深蹲日 / 休息
  - 比如周一选了深蹲，周二不会再推荐硬拉（避免连续两天练下肢），本周剩余的训练会自动重新排
  - 训练日不够时会提醒补练；实在练不完，可以在「计划」里把整个计划顺延一周
- **今天状态**
  - 💪 很好：带 "+" 的组可以多做几次
  - 🙂 正常：完全按计划
  - 😮‍💨 疲劳：跳过 100% / 110% 单次组，"+" 组只做规定次数，第二主项减到 3 组、重量降 10%，辅助只做 1 个
  - ⏱ 时间紧：只做主项和第二主项
- 每一组打勾记录；"+" 组可以填实际次数，自动估算 1RM
- 辅助动作可以点「换一个」
- **第 12 周**：按预估 1RM 给出热身和试举重量，填入新 1RM 后，下一轮 TM 自动更新

## 训练计划规则（来自原计划图片）

| 周 | 主项 | 第二主项 | 其他 |
|---|---|---|---|
| 1 | 70/80/90% × 3，最后一组 3+，再加 100% × 1 | 70% × 5 组 | 拉类 / 核心 5 组 |
| 2 | 65/75/85% × 5 | 65% × 5 组 | 5 组 |
| 3 | 75/85/95% × 5/3/1+，再加 100% × 1 | 75% × 5 组 | 5 组 |
| 4 | 减载 50/60/70% × 5 | 50% 3 × 10（硬拉 3 × 8） | 3 组 |
| 5 | TM 加重；70/80/90% × 3，再加 100% 全力组 | 70% × 3 组 | 3 组 |
| 6 | 65/75/85% × 5 | 65% × 3 组 | 3 组 |
| 7 | 75/85/95% × 5/3/1，再加 100% 全力组 | 75% × 3 组 | 3 组 |
| 8 | 减载 | 50% × 3 组 | 3 组 |
| 9 | TM 加重；70/80/90% × 3，再加 100% 和 110% 各 1 次 | 70% × 3 组 | 3 组 |
| 10 | 65/75/85% × 5 | 65% × 3 组 | 3 组 |
| 11 | 75/85/95% × 5/3/1 | 无 | 不做任何辅助 |
| 12 | 极限测试：硬拉、卧推、深蹲（推举可选） | | |

- 补充说明：
  - 每周的训练组合：周一推举 + 卧推，周二硬拉 + 深蹲，周四卧推 + 推举，周五深蹲 + 硬拉。
  - 第二主项为硬拉时，每组 5 次；其他第二主项每组 5–8 次。
  - 推举不做 100% / 110% 单次组，改为最后一组做 "+"。
- TM 加重：第 5、9 周上肢 +2.5kg、下肢 +5kg。
- 重量算法：所有重量按 TM × 百分比计算，再四舍五入到你的最小加重单位。原图片里有几处手算错误（例如第 10、11 周卧推），这里以公式为准。

## 辅助动作怎么分配

根据当天主项和第二主项已经练累了哪些部位来挑选，例如：
- **推举日**：优先后束、二头和水平划船。
- **卧推日**：优先三头和垂直拉。
- **硬拉日**：后链已经很累，所以不安排早安式这类压腰的动作，核心练抗伸展、抗旋转。
- **深蹲日**：优先腘绳肌、小腿和握力。

另外几条规则：
- 第二天是下肢日时，前一天少安排压腰的动作。
- 有腰伤时，不会自动安排压腰的动作。
- ❤️ 的动作优先、经常出现；🚫 的动作和器械做不了的动作不会出现。
- 同一天不会安排两个同部位的辅助动作，每周轮换以保持多样性。

## 营养

基础代谢用 Mifflin-St Jeor 公式计算。每日热量按天的类型区分：

- **下肢大重量日**：最高，碳水最多。
- **上肢日**：其次。
- **休息日**：最低。

蛋白质按 1.8–2.2 g/kg 计算，脂肪约 0.8–1.0 g/kg，剩余热量给碳水。练前加餐和练后餐会按你的训练时间安排。

## 安装到手机

把仓库发布到 GitHub Pages（Settings → Pages → 选择分支和根目录），用手机打开网址：
- iPhone：Safari → 分享 → 添加到主屏幕
- Android：Chrome → 菜单 → 安装应用

本地运行：`python3 -m http.server 8000`，然后打开 http://localhost:8000
